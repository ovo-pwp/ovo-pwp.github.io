关于我

我是 ovo-pwp，做前后端分离的全栈开发，也写数据分析。喜欢把一个完整的想法 从界面一直做到数据库——「心屿」用 Spring Boot 3.2 + Vue 3 实现了患者、咨询师、 管理员三种角色的心理健康系统，AI 对话走通义千问并按 SSE 流式返回； 「云端看板」则用 Vue 3 + Express + PostgreSQL 做销售回款的多维分析。

另一条线是数据与展示：用 Python 做共享单车、电商销售趋势与销量预测的分析， 也写了一些直接用浏览器打开的网页作品——校园双校区数据看板、青少年情绪减压工具， 以及免费无广告的多语言学习平台 LingoHub。
